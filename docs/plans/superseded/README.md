# 已取代的计划

本目录保存已被后续 ADR 或已采纳实现策略取代、且未按原方案完成的历史计划。它们不是可执行的实施输入，也不以“完成”为由移入 `completed`。

如需恢复其中的业务目标，必须先以当前 ADR 和 Spec 重新 Grill，并在 `docs/plans/active/` 新建计划；不得直接按本目录的任务清单实施。
