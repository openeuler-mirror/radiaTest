# 实施计划目录

- `active/`：已经完成 Grill、可按清单实施的计划。实现和验证完成后，且已保留审查记录（合入 commit message 或上游 PR 描述），移入 `completed/`。
- `completed/`：已完成实施、验证和审查的计划。
- `superseded/`：被后续 ADR 或已采纳实现策略取代、未按原方案完成的历史计划。不可直接实施；如需恢复其目标，必须重新 Grill 并在 `active/` 新建计划。
